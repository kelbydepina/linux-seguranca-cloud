# Topico-01 - preparacao do ambiente

## Ambiente utilizado
VM  local com VirtualBox, Ubunto Server 26.04.1 LTS 2 CPUs, 1,6 GiB RAM, disco 25 GB.

## Objetivo desta Actividade
prepara o ambiente linux e organizar a primeita evidencia tecnica.

## Estrutura Criada
linux-seguranca-cloud/ com topico-01/ (evidencias, comandos, README) e produto-final/.

## Comandos Executados
whoami, hostname, unane -a, (utilizadores, maquina e karnel.
- cat /etc/os-release (distribuicao e versao)
- df -h, free -h, nproc (disco, memoria e CPUs
- mkdir , touch, mv, cd, tree (criar e verificar pasta)

## Diferenca entre MV, VPS, e nuvem
- VM local (maquina virtual no meu computador)
- VPS (servidor virtual alugado, sempre ligado, com IP publico.
- nuvem (servicos escalaveis pagos conforme o uso.
