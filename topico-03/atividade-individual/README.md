# Atividade prática individual - Tópico 3

## Nível realizado
Nível 2 - Intermédio

## Objetivo
Criar e publicar um serviço na web em ambiente Linux.

## Ambiente utilizado
VM local (VirtualBox) com Ubuntu Server 26.04.1 LTS

## Rota de publicação
Nginx

## Ficheiros criados
- site/index.html
- site/sobre.html
- site/style.css
- comandos.txt, publicacao.md, validacao.md e README.md

## URLs testados
- http://localhost/topico-03/
- http://localhost/topico-03/sobre.html
- http://localhost:8080/topico-03/ (navegador do Windows)

## Evidências produzidas
Pasta evidencias/ com o output dos testes curl e os prints do navegador.

## Dificuldades encontradas
Configuração do reencaminhamento de portas para aceder ao site pelo navegador do Windows e da autenticação no GitHub com token.
