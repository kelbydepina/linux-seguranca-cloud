Serviço web em Linux

Módulo: Linux, Segurança e Cloud
Tópico: 3 – Publicação de serviços web

Descrição da iniciativa

Este pequeno site foi criado para apresentar uma iniciativa digital e demonstrar a publicação de um serviço web num servidor Linux com Nginx.

Componentes usados

  • Ubuntu Server 26.04.1 LTS numa VM VirtualBox
  • Servidor web Nginx
  • HTML e CSS
  • Git e GitHub

O que aprendi

Aprendi a criar conteúdo web, a publicá-lo com o Nginx em /var/www/html e a validar o serviço com o curl e com o navegador.
