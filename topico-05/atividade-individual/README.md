# Atividade prática individual - Tópico 5

## Nível realizado
Nível 2 - Intermédio (inclui a monitorização e os logs do Nível 1 e uma proposta de continuidade)

## Objetivo
Acompanhar o estado do sistema, consultar logs, criar um backup e testar uma recuperação simples.

## Ambiente utilizado
VM local (VirtualBox) com Ubuntu Server 26.04.1 LTS e Nginx

## Ficheiros criados
- monitorizacao.md
- logs.md
- manutencao.md
- backup-recuperacao.md
- continuidade.md
- comandos.txt
- evidencias/

## Evidências produzidas
Outputs de monitorização, logs, backup e restauro, e prints dos testes.

## Dificuldades encontradas
